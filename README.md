# Lewis Lee — 李昌黎

> 非凡的主张需要非凡的证据

个人主页，纯 HTML/CSS/JS 手写，零外部依赖。

在线地址：**[lewisleeyu-air.github.io/lewis-personal-website](https://lewisleeyu-air.github.io/lewis-personal-website/)**

## 技术栈

- 纯 HTML + 内联 CSS + 内联 JS
- 无框架、无构建工具、无外部 CDN
- 衬线/无衬线双字体系统（Noto Serif SC / PingFang SC）
- 响应式布局（桌面/平板/移动端三断点）
- IntersectionObserver 滚动揭示动画
- 逐字解码动画（Scramble 效果）

## 页面结构

| 板块 | 内容 |
|------|------|
| Hero | 座右铭、身份、CTA |
| 关于 | 个人信息、教育背景、爱好标签 |
| 经历 | 比赛（创新创业/工科竞赛）、个人开发项目 |
| 生活 | 三列独立滚动（旅行/美食/纪念） |
| 联系方式 | 邮箱、GitHub 等 |
